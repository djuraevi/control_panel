# Панель управления арендаторами, зданиями и объектами

Приложение на Vue 3, Vite, Pinia, Vue Router и Bootstrap 5.

## Что реализовано

- Главная таблица клиентов с колонками: №, компания, директор, телефон, здание, № договора, дата создания, объекты, статус договора.
- Сортировка кликом по заголовкам таблицы с сохранением направления.
- Поиск по компании, директору, телефону, номеру договора, зданию и статусу.
- Фильтр по статусу договора, пагинация, пустые состояния, loading/error states.
- Состояние поиска, фильтра, сортировки и страницы сохраняется в URL.
- Карточка клиента в боковой панели: основная информация, договоры, объекты и комментарии.
- Редактирование этажа объекта с сохранением в локальном состоянии и пересчётом этажей здания без перезагрузки страницы.

## Архитектура

- `src/repository` — имитация API над локальным JSON.
- `src/stores` — Pinia-хранилища для данных клиентов и UI-состояния.
- `src/domain` — типы и selectors.
- `src/composables` — UI-логика и сценарии отображения.
- `src/components/ui` — переиспользуемые базовые элементы без бизнес-логики.
- `src/components/clients` и `src/pages` — клиентские сценарии и страницы.
